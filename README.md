# Tiny Adventures iOS App

Tiny Adventures is a modern e-commerce iOS application built with SwiftUI. The app is designed for parents to shop organic, non-toxic clothing, toys, and essentials for babies and toddlers. The goal of the app is to create a clean, simple, and trustworthy shopping experience while still feeling warm and visually appealing.

The app includes a full shopping experience similar to real retail apps. Users can browse products through different sections like Home, Collections, and Trending, and explore categories such as Girls, Boys, Unisex, Nursery, and Toddler & Kids. They can also shop by style, including items like footies, rompers, bodysuits, dresses, and accessories. Each product has its own detail page where users can select sizes and colors, view descriptions, browse multiple images depending on the selected color, and read or write reviews.

The app also includes a wishlist feature, where users can save items using a heart icon, and a cart system that allows them to adjust quantities and see how many items they have selected. There is also an account section where users can create an account, sign in, and view options like order history, address book, and rewards. Input validation is included to make sure all required fields are completed when creating an account.

From a technical perspective, the app is built using SwiftUI and follows a structured approach similar to MVVM. The product data is stored locally in the app using Swift models that are designed to resemble a JSON structure. Each product includes details such as name, price, available sizes and colors, descriptions, reviews, and a mapping system that connects each color to its corresponding images. This allows the app to simulate how real e-commerce apps load data from APIs while still working offline.

Artificial intelligence was used throughout the development process to improve efficiency and support problem-solving. ChatGPT was used to help generate SwiftUI code, fix errors, and implement features such as navigation, filtering, sorting, and dynamic image updates based on selected product colors. It was also used to design the structure of the app, including the layout of tabs, product categories, and user flow.

For example, prompts such as “Provide SwiftUI code for a shopping app with categories, cart, wishlist, and product detail views including size and color selection” were used to help build the foundation of the app. AI was also used iteratively to refine the user experience, improve layout spacing, fix bugs, and enhance the overall design.

The design of the app was inspired by modern baby brands like L’ovedbaby. It uses soft colors such as greens, pinks, blues, and neutral tones to create a calm and friendly look. The focus was on making the interface feel simple, elegant, and easy to use.

In the future, this project could be expanded by connecting it to a real backend, adding payment functionality, implementing real user authentication, and improving search and performance features.

This project represents both technical development skills and the ability to design a user-friendly digital product from start to finish.
